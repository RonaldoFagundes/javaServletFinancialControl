

  # 💰 FinancialSystem

Sistema de Gestão Financeira desenvolvido em Java Web utilizando Servlets, JSP, JavaScript, HTML5, CSS3 e MySQL.

O sistema permite autenticação de usuários e gerenciamento de bancos, contas, investimentos, cartões e transações financeiras.

---

## 📌 Sobre o projeto

O **FinancialSystem** é uma aplicação web para gerenciamento financeiro pessoal.

O projeto foi desenvolvido utilizando uma arquitetura baseada em:

- Java Servlets
- JSP
- DAO
- Models
- Filters
- MySQL
- JavaScript
- HTML5
- CSS3
- Apache Tomcat

A aplicação possui autenticação de usuário e utiliza `HttpSession` para controlar o acesso às áreas protegidas.

# 💰 Sistema de Gestão Financeira

Sistema web de gestão financeira desenvolvido em **Java**, utilizando **Servlets, JSP, JavaScript, HTML5, CSS3, MySQL e Apache Tomcat**.

O projeto tem como objetivo disponibilizar uma interface para gerenciamento de bancos, contas, investimentos e transações financeiras.

---

## 📌 Sobre o projeto

O Sistema de Gestão Financeira permite ao usuário acessar uma área autenticada para administrar suas informações financeiras.

Entre as funcionalidades planejadas/implementadas estão:

- 🔐 Login de usuário
- 🚪 Logout
- 🔒 Controle de sessão
- 🏦 Cadastro e seleção de bancos
- 💳 Gerenciamento de contas
- 💰 Controle de saldo
- 📈 Investimentos
- 💸 Resgates
- 🔄 Transferências
- 💳 Pagamentos
- 💵 Saques
- 💳 Cartão de crédito
- 📊 Transações financeiras
